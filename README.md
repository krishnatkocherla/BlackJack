# BlackJack

A simple and fun **BlackJack** game implemented in Python using PyGame. This repository provides the main game logic, user interaction, and gameplay flow—perfect for learning card game mechanics and basic Python scripting.

## Overview

This project implements the classic casino game **BlackJack**, also known as 21. The goal is to get your card total as close to 21 as possible—without going over—to beat the dealer.

---

## Features

- Standard BlackJack rules: hit, stand, handle aces as 1 or 11, and dealer gameplay.
- Simple, interactive command-line interface.
- Scoring and game-flow mechanics to simulate a realistic game experience.
- Easily extendable for features like betting, multiple hands, or GUI integration.
